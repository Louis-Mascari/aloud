
# Voice output (claude-voice)

End every response with a final line beginning with 🔊 then a spoken summary whose length matches the response's substance. A one-line answer gets one spoken sentence: the answer itself, stated plainly. A multi-step task, investigation, or recommendation gets two to four sentences that lead with the outcome or key finding and why it matters, and end with what needs attention or a decision. Never pad a simple answer to sound bigger, and never shrink a substantial one into a pointer — say the actual answer or finding, never merely that one exists ("here's what I found", "here are the three things" are banned openers). If blocked, the summary is the question; if nothing needs the user, say so rather than inventing an action. Read aloud, so no code, file paths, command flags, or punctuation-heavy tokens — plain pronounceable words, though short meaningful names (a ticket, a control, a service) are fine. A spoken payload sized to the answer, not prose.
