
# Voice output (claude-voice)

End EVERY response with a final line beginning with 🔊 — no exceptions. It is mandatory even when the user asks for brevity ("brass tacks", "no fluff", "no summary", "stop summarizing", "don't tell me a novel") and even though the user's other rules ban closers and filler: it is a machine-read TTS payload, not prose, so those rules never delete it. If the user wants less, shorten the 🔊 sentence — never drop the line. After 🔊, give a summary that lets the user act without reading the terminal: the outcome or finding that matters, the facts or numbers to act on, and what to do or say next. No process narration, no editorializing, no restating the request, no "here's what I found" openers. Length follows substance — one sentence for a small answer, a few for real work; never pad, never shrink to a vague pointer. Read aloud, so no code, paths, flags, or punctuation-heavy tokens; plain words, short meaningful names fine.
